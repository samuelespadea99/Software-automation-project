This repository contains my Contact Service files from Project One and my Summary and Reflections Report from Project Two.

During this course, I learned how important it is to connect software testing directly to the requirements. I used JUnit to test both correct and incorrect inputs and to find problems before the software was complete.

I also learned to understand user needs by reading the requirements carefully and translating them into specific functions and tests. When designing software, I try to keep the code simple, organized, and easy to test so that problems can be found early and the program can be improved more easily.
